# NSSM

**全称**：Non-Sucking Service Manager

**一句话**：把任意 exe、bat、php-cgi、nginx 等控制台程序包装成 Windows 系统服务，自带进程守护，程序崩溃自动重启。

感谢作者的无私奉献。

## 本项目说明

本项目只是做了一下汉化，添加了右键菜单，可以自由切换语言，同时进行了一些体验优化。

- **汉化**：界面、命令行、事件日志全部中文化（English / 中文 / Français / Italiano 四语言）
- **右键菜单**：在安装 / 编辑 / 卸载对话框里右键即可自由切换语言，且切换时保留未提交的编辑内容
- **体验优化**

详细构建、汉化与配置说明见 [汉化构建说明.md](汉化构建说明.md)。
